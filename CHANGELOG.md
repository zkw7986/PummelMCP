# 更新记录 / Changelog

## 0.6.0b1 — 2026-10-06

### 中文

首次公开实验版，发布 67 个 MCP 工具、PMH 读取及有限安全写入能力、五个初始化模板、实验性完整文件制作 v0.3、Blender 场景导入和手动试玩证据工具。

提供中文在前的双语 README、安装与客户端配置指南，以及主动搜索模型、贴图、音效和 BGM 的制作规则。仓库排除作者个人素材、交付游戏、完整游戏资源、研究产物和本机环境。

这是核心工具初版，并非编辑器全部功能的完整自动化；部分复杂玩法仍需要额外脚本或编辑器操作。静态构建成功不代表游戏内玩法、物理或联机验证通过。使用者需要自己安装游戏并配置本机路径。

### English

Initial public experimental release: 67 MCP tools, PMH reading and bounded safe writing, five starter templates, experimental full-file authoring v0.3, Blender scene import and manual playtest evidence tools.

Includes a Chinese-first bilingual README, installation/client configuration guide and proactive sourcing rules for models, textures, sound effects and BGM. Personal assets, delivered games, the full game resources, research outputs and the author's local environment are excluded.

This is a core-tool release, not complete automation of every editor feature. Some complex mechanics still need additional scripts or editor work. Successful static builds do not prove runtime gameplay, physics or multiplayer behavior. Users need their own game installation and local path configuration.
