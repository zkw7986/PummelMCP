# Minigame report

The build report records minigame/composition identity, requested and actual
completion levels, spec and plan hashes, raw and semantic Scene identity,
logical-ID/GUID mappings, created Actions, asset/template hashes, capabilities,
gaps, runtime expectations, and repair status. Stage 14 later supplies the
manual-start PlaytestReport. Reports distinguish `BUILD_PASS`, runtime states,
and capability-blocked plans.
